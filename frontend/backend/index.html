05문제 해결

운영 중 겪은 장애와 대응 과정입니다.

Case 01

DB 서버 부팅 중 Emergency 모드 진입

문제
서버 이전 후 DB 서버가 부팅 중 Emergency 모드로 진입
원인 분석
외장 디스크 미감지로 마운트 실패 → 스토리지 케이블 연결 불량
조치
Reseat로 서비스 우선 복구
근본 해결
디스크 하나의 문제가 부팅 전체를 멈추는 원인 추적 → /etc/fstab에 nofail 옵션 부재 확인, 협의 후 설정 보완해 재발 조건 제거
Case 02

해외 서버실 SAN 스토리지 연결 장애

문제
서버 이전 후 재기동 과정에서 일부 서버가 SAN 스토리지에 연결되지 않음
중요성·제약
스토리지가 붙지 않으면 상위 서비스 전체 기동 불가. 서버실이 해외에 있어 장비를 직접 확인할 수 없음
판단
원인을 설정 문제 / 물리 문제로 나눠 가설 수립 → 경로별 테스트 케이스로 핑 테스트 반복 → 실패에 규칙성이 없다는 점을 근거로 물리 계층 의심
결과
근거를 현지에 공유해 확인 범위를 케이블로 좁힘 → 포설 문제 특정, 약 6시간 만에 복구
Case 03

vMotion이 어려운 호스트의 업그레이드

문제
운영 서버가 올라간 ESXi 호스트 업그레이드 필요
제약
로컬 디스크를 사용하는 호스트 8대는 vMotion으로 VM 이전이 어려움
판단
무리한 이전 대신 서비스 담당자와 협의해 정해진 시간에 VM Shutdown 후 업그레이드
결과
대상 VM·중단 시간·작업 순서를 작업계획서로 정리해 일정 조율, 업그레이드 완료
